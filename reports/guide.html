技术雷达 — 使用说明

自动发现、提取、搜索代码中的可复用技巧和架构模式
01 / WHAT IS IT

这东西是干嘛的？

你平时逛 GitHub 看到好代码，会想「这个写法不错，下次用得上」——
但过几天就忘了在哪看的、怎么写的。

技术雷达就是帮你自动干这件事的工具：
扫描代码 → AI 提取精华 → 存成卡片 → 随时搜索。

相当于你的「代码笔记本」，只不过记笔记的活儿交给 AI 了。

03 / STEP BY STEP

每一步具体做了什么

STEP 01 / DISCOVER
发现新仓库
调用 GitHub API，按主题（ai-agent、mcp-server 等）搜索最近活跃的高星仓库。 找到后让 AI 快速打个分（1-10 分），低于 4 分的直接跳过，省得浪费时间。 结果存到 candidates.json。
powershell -File discover.ps1
STEP 02 / ANALYZE
AI 分析源码
把源码喂给 Claude，让它像高级工程师一样审查代码。
提取出「这个问题怎么解决的」「精华代码片段」「什么场景能复用」。
每个技巧生成一张技术卡片（Markdown 文件），存到 cards/ 目录。 同时更新 index.json 索引。
powershell -File analyze.ps1 -Source "https://github.com/user/repo"
STEP 03 / SEARCH
搜索知识库
输入关键词，搜索你积累的所有技术卡片。
支持按标签、来源类型、评分等过滤。
标题和标签匹配会加分，全部关键词都命中还有额外加分。
powershell -File search.ps1 -Query "async agent pattern"
STEP 04 / DAILY PIPELINE
每日自动流水线
一键执行：发现新仓库 → 自动分析高分候选 → 生成当日摘要。
可以用 Windows 任务计划程序设定每天早上自动跑，实现全自动知识积累。
powershell -File daily-pipeline.ps1

05 / FILE STRUCTURE

项目文件一览

所有文件分三类：主脚本（干活的）、共享库（被复用的工具）、测试（验证代码正确性的）。

analyze.ps1 源码分析器
discover.ps1 仓库发现器
search.ps1 知识库搜索
daily-pipeline.ps1 每日自动化
deploy.ps1 一键部署
lib-json.ps1 JSON 读写工具
lib-claude.ps1 AI 调用 + 安全验证
tests/*.Tests.ps1 82 个自动化测试
PSScriptAnalyzerSettings.psd1 代码规范配置

运行时会产生的数据文件：

index.json 所有卡片的索引
candidates.json 待分析的仓库列表
cards/*.md 每张技术卡片

07 / QUICK START

快速上手

FIRST / DEPLOY
第一步：部署
运行部署脚本，自动复制所有文件到正确位置。
powershell -NoProfile -ExecutionPolicy Bypass -File deploy.ps1
THEN / ANALYZE
第二步：分析一个仓库试试
选一个你感兴趣的 GitHub 项目，让 AI 提取技巧。
powershell -File analyze.ps1 -Source "https://github.com/browser-use/browser-use"
THEN / SEARCH
第三步：搜索你的知识库
分析完成后，试试搜索刚提取的技巧。
powershell -File search.ps1 -Query "agent async"
OPTIONAL / AUTOMATE
可选：设置每日自动运行
用 Windows 任务计划程序，设定 daily-pipeline.ps1 每天早上自动运行。
之后每天起床，知识库里就多了新的技巧卡片。
powershell -File daily-pipeline.ps1
08 / FAQ

常见问题

QUESTION

需要联网吗？

分析 GitHub 仓库需要联网（克隆代码 + 调用 AI）。分析本地代码只需要 Claude CLI。搜索完全离线。

QUESTION

需要 API Key 吗？

不需要。使用本地已认证的 Claude CLI，零 API 成本。GitHub Token 可选（有了能搜更多仓库）。

QUESTION

分析一个仓库要多久？

通常 1-3 分钟。取决于仓库大小和 Claude 响应速度。超时默认 180 秒，可通过 -Timeout 调整。

QUESTION

卡片会重复吗？

不会。每个源有唯一哈希值，分析过的源会自动跳过。想重新分析加 -Force 参数。

QUESTION

支持什么语言？

Python、JavaScript/TypeScript、Go、Rust、PowerShell、Shell 等，只要 Claude 能读懂的代码都行。

QUESTION

Windows 版本要求？

Windows 10/11 自带的 PowerShell 5.1 就行，不需要装 PowerShell 7。完全兼容。
